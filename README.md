# 📚 Error Makes Clever Academy Web Page

![HTML](https://img.shields.io/badge/HTML-5-E34F26?logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS-3-1572B6?logo=css3&logoColor=white)
![Status](https://img.shields.io/badge/status-learning%20project-yellow)

An educational web page for **Error Makes Clever Academy**, built with semantic HTML5. The project presents the academy, introduces full-stack development, showcases commonly used technologies, and provides a simple course registration form.

---

## ✨ Key Features

- 🚀 **Academy Introduction** – Displays the academy name, training focus, and developer-focused message.
- 🎥 **Embedded Learning Video** – Includes a YouTube video about full-stack development.
- 🧩 **Full-Stack Overview** – Introduces frontend, backend, and database development.
- 🛠️ **Technology Table** – Lists example tools and languages used across the stack.
- 📝 **Course Registration** – Collects student details, course selection, and resume uploads.
- 🔗 **Useful Links** – Connects visitors to the registration page, Instagram, and YouTube.
- 📄 **Two-Level Structure** – Includes starter files for practice and completed files for reference.

---

## 🧰 Technologies Used

- **HTML5** – Page structure, headings, lists, tables, forms, and embedded media.
- **HTML Forms** – Text, number, email, radio, select, file, reset, and submit controls.
- **YouTube Embed** – External video content displayed with an iframe.

---

## ▶️ How to Run

1. Clone or download this repository.
2. Open the `EMC Web Page HTML Project` folder.
3. Open `final/findex.html` in a web browser.
4. Select **Register for a Course** to open the registration page.

No build tools or dependencies are required.
